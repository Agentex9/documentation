# 📘 Manual de Usuario - Tecnigame
## 🎮 Bienvenida
¡Bienvenido a Tecnigame! Este juego ha sido diseñado para ayudarte a aprender de forma interactiva a través de distintos cursos. A continuación, te explicamos paso a paso cómo utilizar el juego.

## 🔐 Inicio de Sesión
1. Al abrir el juego, se te pedirá que introduzcas tus credenciales.
2. Usa el *usuario y contraseña previamente generados*.
3. Si los datos son correctos, accederás al menú principal con la lista de cursos disponibles.

## 📚 Selección de Curso
1. En la pantalla de cursos, elige uno haciendo clic sobre él.
2. Al seleccionar un curso, comenzarás con una serie de diapositivas.

## 🧩 Progreso en el Curso
- Las diapositivas pueden contener *información* o *preguntas*.
- Si es información, presiona el botón *"Siguiente"* para continuar.
- Si es una pregunta, selecciona la *respuesta correcta* para avanzar.
- Debes responder correctamente para poder continuar a la siguiente parte del curso.

## 🏁 Final del Curso
- Al terminar todas las diapositivas, el juego evaluará tu desempeño:
  - Si cometiste *menos de tres errores, verás una **escena de victoria* 🎉.
  - Si cometiste *tres o más errores, verás una **escena de fallo* ❌.

## 🔁 Después del Curso
- Después de ver la escena final (victoria o fallo), volverás automáticamente a la *lista de cursos*.
- Desde ahí, puedes:
  - Volver a intentar el curso.
  - Seleccionar un curso diferente.

## 📝 Recomendaciones
- Lee con atención cada diapositiva antes de responder.
- Si tienes dudas sobre tus credenciales, contacta a tu supervisor o encargado.
